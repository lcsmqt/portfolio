# Gringa Chloe — agendamento online de aulas

Sistema de agendamento para uma professora de inglês, publicado em [agendar.gringachloe.com](https://agendar.gringachloe.com).

**Problema:** marcar aulas e receber pagamentos por mensagem tomava tempo e gerava remarcações e esquecimentos.

**Solução:** o aluno escolhe um horário livre, informa os dados, paga por Pix e recebe a confirmação. A aula individual de 30 minutos acontece pelo Zoom.

| | |
|---|---|
| **Fluxo** | Horário → Dados → Pagamento, em 3 etapas |
| **Integrações** | Google Agenda, Zoom e pagamento via Pix |
| **Regras** | Agendamento com antecedência mínima e remarcação até 2 horas antes |
| **Stack** | Next.js |

> Esta vitrine mostra apenas a descrição do projeto. Código-fonte, credenciais e dados de alunos não são públicos.
