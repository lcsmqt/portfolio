# Snap Lab Academy

**Tipo:** Pacote de growth marketing para academia de artes marciais  
**Stack:** HTML/CSS, Node.js (chatbot API)  
**Papel:** Landing page, chatbot IA 24/7, calculadora de funil e estratégia de aquisição

## Escopo

- Landing page em inglês para anúncios pagos
- Chatbot IA para captura de leads (Instagram, Facebook, web)
- Calculadora de ROI do funil de conversão
- Plano de ação 30/60/90 dias para aquisição de alunos
- Proposta comercial e apresentação visual
